# AI가 내 캐릭터만 자꾸 바꾸는 이유

> **AI로 만든 그림입니다.** 이 폴더의 두루 그림은 모두 AI 이미지 생성으로 만들었습니다. 그림마다 어느 도구로 만들고 어떻게 손봤는지 아래에 적었습니다.

- 영상: https://youtu.be/QxF86tUa7b0
- 공개일: 2026-07-15 (한국 시각)
- 그림 수: 5

## 그림과 출처

| 파일 | 무엇으로 만들었나 | 어떻게 손봤나 |
|---|---|---|
| `bad1.png`, `bad2.png`, `bad3.png` | **힉스필드 생성 그림**. 힉스필드(Higgsfield)에서 생성한 원본입니다(원래 파일 이름이 hf_날짜_시각_작업번호 형식). 영상에서 「AI가 그릴 때마다 달라진 두루」 예시로 썼습니다. 그림은 손대지 않았고, 공개본에서는 파일 안의 힉스필드 작업 번호(hf-job-id) 글자 하나만 뺐습니다. | 그림은 그대로이고, 파일 안 작업 번호 글자만 뺐습니다. |
| `char_clean.png` | **도구 기록이 없는 그림**. AI로 만든 두루 그림입니다. 어느 도구로 만들었는지 남은 기록이 없습니다. | 손대지 않았습니다. |
| `sheet.png` | **모델 시트**. 코드로 합친 한 장입니다. 정면, 3/4, 뒷모습은 생성 그림 한 장에서 오렸습니다. 그 생성 그림을 어느 도구로 만들었는지는 파일 기록이 없고, 같은 날 인계서에 힉스필드 nano_banana로 시트용 그림을 만들었다는 기록만 있습니다. 옆모습과 표정, 부위 그림은 힉스필드로 만든 두루 영상의 낱장입니다. rembg(isnet-anime)로 배경을 지우고 발밑 그림자를 지운 뒤 한국어 설명 글자와 색상표를 코드로 붙였습니다. | 왼쪽 설명 참고. |

## 여기 없는 것

두루 영상 클립(힉스필드로 만든 움직이는 영상)도 나오지만 그건 그림 파일이 아니라서 넣지 않았습니다. 이 폴더는 영상의 최종 렌더 코드를 다시 실행해 실제로 그려진 그림 파일을 기록하고, 그중 두루가 나오는 그림만 골라 담았습니다. 썸네일, 배경, 소품, 글자 그림은 넣지 않았습니다.

## English

> **These pictures were made with AI.** Every Duru picture in this folder was made with AI image generation. Below is which tool made each group and how it was edited.

- Video: https://youtu.be/QxF86tUa7b0 ("Why AI keeps changing MY character")
- Published: 2026-07-15 (KST)
- Pictures: 5

### Pictures and sources

| Files | How it was made | Edits |
|---|---|---|
| `bad1.png`, `bad2.png`, `bad3.png` | **Higgsfield images**. Original images generated on Higgsfield (the original file names were hf_date_time_jobid). The video uses them as examples of Duru coming out differently each time. The pixels are untouched; only the Higgsfield job-id text chunk was removed from the public copy. | Pixels unchanged; only the job-id text chunk was removed. |
| `char_clean.png` | **No tool record**. An AI-generated drawing of Duru. No record remains of which tool made it. | Not edited. |
| `sheet.png` | **Model sheet**. Assembled in code. The front, three-quarter and back views were cut from one generated image. There is no file record of which tool made that image; a handover note from the same day only says sheet images were made with Higgsfield nano_banana. The side view, the expressions and the detail callouts are frames from Duru videos made on Higgsfield. Backgrounds were removed with rembg (isnet-anime), the ground shadow was erased, and Korean labels and a color chart were added in code. | See the left column. |

### Not included

Duru also appears in moving video clips made on Higgsfield. Those are video, not picture files, so they are not here. This folder was filled by running the video's final render code again, recording every picture file it drew, and keeping only the ones that show Duru. Thumbnails, backgrounds, props and text images are not included.
