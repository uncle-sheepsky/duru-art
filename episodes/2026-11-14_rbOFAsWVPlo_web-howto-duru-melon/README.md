## 여기 없는 것

웹 페이지에 두루와 멜론을 넣어 보는 숏츠입니다. 영상 속 두루는 페이지가 이 그림(`web/duru.png`, 원래 이름 `clapwait_cel01.png`)을 색 층으로 나눠 그린 것이고, 페이지가 만든 영상 장면도 같은 그림에서 나왔습니다. 멜론은 두루가 아니라서 넣지 않았습니다. 이 폴더는 영상의 최종 렌더 코드를 다시 실행해 실제로 그려진 그림 파일을 기록하고, 그중 두루가 나오는 그림만 골라 담았습니다. 썸네일, 배경, 소품, 글자 그림은 넣지 않았습니다.
