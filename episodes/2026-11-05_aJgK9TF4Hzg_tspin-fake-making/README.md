## 여기 없는 것

방 배경과 소품 그림은 두루가 아니라서 넣지 않았습니다. 화면 안에 나오는 테트리스 숏폼 장면 속 캐릭터는 영상 클립이라 그림 파일이 없습니다. 이 폴더는 영상의 최종 렌더 코드를 다시 실행해 실제로 그려진 그림 파일을 기록하고, 그중 두루가 나오는 그림만 골라 담았습니다. 썸네일, 배경, 소품, 글자 그림은 넣지 않았습니다.
