# 두루 그림 (duru-art)

> **AI로 만든 그림입니다.** 이 저장소의 두루 그림은 전부 AI 이미지 생성으로 만들었습니다. 대부분은 OpenAI 이미지 모델(OpenAI Codex에 들어 있는 이미지 생성 도구 image_gen)로 만들었고, 한 편의 그림 몇 장은 힉스필드(Higgsfield)로 만들었습니다. 어느 도구로 만들었는지 기록이 남지 않은 그림도 있습니다. 그림마다 무엇으로 만들고 어떻게 손봤는지는 [AI-NOTICE.md](AI-NOTICE.md)와 편 폴더의 README에 적었습니다.

유튜브 채널 「아낌없이 주는 두루」(https://www.youtube.com/@duru-ai0503) 영상에 나온 두루 그림을 편마다 폴더 하나로 모았습니다. 지금은 19편, 파일 984개입니다. 같은 그림이 여러 편에 나오면 편마다 넣었습니다.

## 어떻게 골랐나

2026-11-14에 편마다 최종 렌더 코드를 다시 띄워 처음부터 끝까지 모든 프레임을 넘기면서, 실제로 화면에 그려진 그림 파일을 기록했습니다. 그 가운데 두루가 나오는 그림만 남겼고, 썸네일과 배경, 소품, 글자 그림은 넣지 않았습니다.

영상 속에 다른 편 영상 장면이 들어간 경우, 그 장면에 나오는 두루는 원래 편 폴더에 있습니다. 렌더가 그림을 코드로 색 층으로 나눠 읽은 편(「WHAT YOUR COLOR.」)은 나눈 파일 대신 원래 그림을 넣었습니다.

## 파일 확인

[MANIFEST.txt](MANIFEST.txt)에 이 저장소 모든 파일의 sha256이 있습니다. 공개하면서 파일 안 메타데이터를 뺀 그림은 영상에 쓴 원래 파일의 sha256도 함께 적었습니다.

```bash
grep -v '^#' MANIFEST.txt | awk -F'\t' '{print $1"  "$2}' | sha256sum -c
```

## English

> **These pictures were made with AI.** Every Duru picture in this repository was made with AI image generation. Most were made with OpenAI's image model (the image tool image_gen inside OpenAI Codex), and a few pictures in one episode were made with Higgsfield. For some pictures no record remains of which tool made them. [AI-NOTICE.md](AI-NOTICE.md) and the README in each episode folder say how each picture was made and edited.

This repository collects the Duru pictures that appear in the videos of the YouTube channel "아낌없이 주는 두루" (https://www.youtube.com/@duru-ai0503), one folder per video. Right now that is 19 videos and 984 files. When the same picture is used in several videos, each folder has its own copy.

CC0 1.0 Universal. No credit needed. You can change, sell and share the pictures. The full text is in [LICENSE](LICENSE).

The video files are not in this repository. The music used in the videos is in [duru-ai-cc0-bgm](https://github.com/uncle-sheepsky/duru-ai-cc0-bgm) (CC0).

### How the pictures were chosen

On 2026-11-14 the final render code of each video was run again and stepped through every frame from start to end, recording each picture file that was actually drawn. Only pictures that show Duru were kept. Thumbnails, backgrounds, props and text images are not included.

When a video shows scenes from another video, the Duru in those scenes is in that other video's folder. For the one video whose render split the pictures into color layers in code ("WHAT YOUR COLOR."), the original pictures are included instead of the layer files.
